# Live Generation Policy

Generated content is allowed, but generation is not validation.

## Before asking a generated scored question

The host must silently check:

1. Is there one clear intended answer?
2. Is the fact stable rather than time-sensitive?
3. Are common aliases, translations, and spelling variants known?
4. Does the wording avoid hidden assumptions?
5. Is the difficulty appropriate for the active player?
6. Has a near-duplicate already appeared?
7. Can the host give a short, accurate explanation?

If any answer is no, rewrite the item or choose a curated one.

## Avoid in scored live generation

- current officeholders, rankings, prices, records, or game updates unless verified live;
- trick wording;
- disputed historical claims;
- questions with several equally valid answers;
- hyper-local facts without a source;
- copyrighted text reproduction;
- stereotypes tied to age, nationality, ability, or interests.

## Promotion into the bank

Do not automatically save generated content. After the session:

1. record the exact wording and answer;
2. verify the fact using an authoritative source when needed;
3. add aliases and an explanation;
4. assign an ID and `reviewed` status;
5. play-test it;
6. promote status only with evidence.

## Fallback

When validation confidence is low, use a non-scored format, ask a preference question, switch games, or select another curated item.
