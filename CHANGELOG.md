# Changelog

## [0.2.1] — 2026-09-30

### Removed

- Family-specific example configuration and personal route details from the public repository.

### Changed

- Documentation examples now use generic player names.
- README advises keeping completed family configurations private.
## [0.2.0] — 2026-09-30

### Added

- Hybrid curated-plus-generated content strategy.
- Content schema, lifecycle, and live-generation validation policy.
- Thirty reviewed quiz questions across six themes.
- Twelve Who Am I clue sets and twelve Guess the Animal clue sets.
- Twenty Would You Rather prompts and twenty 20 Questions targets.

### Changed

- Bootstrap prompt now prefers curated bank items before generating.
- Framework and game catalogue now reference the content library.
## [0.1.0] — 2026-09-30

### Added

- Voice-native family host framework.
- Short and Road Trip mode specifications.
- Voice, state, scoring, turn-taking, and ambiguity policies.
- Successful, unvalidated, weak, and rejected game categories.
- Narrative and journey-linked concepts.
- Reusable privacy-safe family configuration template.
- Bootstrap/customization prompts.
- Failure catalogue, session template, and evidence ledger.

### Known limitations

- Small, informal source play-test set.
- No controlled comparison, platform diarization, or automatic fact checking.
- Several narrative and long-form formats remain proposed.

Future entries should use Added, Changed, Fixed, Removed, and Evidence sections.
