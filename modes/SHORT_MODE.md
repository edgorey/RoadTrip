# Short Mode

**Target:** roughly 5–15 minutes.

- Start the first playable interaction within about two host turns.
- Infer defaults and minimize setup.
- Use fast, disposable formats without long narrative dependency.
- Make stopping at any moment feel complete.
- Prefer one game, or at most one clean switch.

Flow: confirm players only if unclear; state game and turn order in one sentence; play immediately; continue without per-item permission prompts; on arrival or stop, give a one-sentence result.

Good defaults: Quiz, True/False, Who Am I?, Guess the Animal, 20 Questions, Categories, or Would You Rather.

Example: “Short Mode. Player One versus Player Two. Seven minutes. Start with geography.”
